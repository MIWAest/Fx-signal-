# 帯FX 深逆張りバスケット — シグナルエンジン

## 使い方
    cd ~/fx_signal_engine
    python3 engine.py

- **1日1回**叩く（日足が確定する日本の朝がおすすめ）
- 出た「今日の指示」通りに、**マイクロ口座で MIWA が発注**（このスクリプトは指示係・自動発注はしない）
- ポジ状態は `state.json`、決済履歴は `ledger.csv` に自動で溜まる

## ルール(検証済み・ルールカード2026-07-29)
- 売買6ペア: AUD/NZD, EUR/CHF, EUR/GBP, AUD/CAD, EUR/NOK, EUR/SEK （USD/CADは監視のみ）
- 入口: RSI-14 ≤25→買い / ≥75→売り（いっぺんに・乗せない・ナンピンせん）
- 出口: RSI50に戻る / 20営業日 / −2%逆行 の早い方
- サイズ: 小粒・等ウェイト

## 目的
実約定(スプレッド/滑り/スワップ)が backtest と合うか、**小粒の実弾で答え合わせ**する段階。儲けやのうてデータ取り。
